# Szép szó — венгерский с нуля

Публичная версия: https://gelyasn.github.io/szep-szo/ (сайт на GitHub Pages).

Откройте **`index.html`** двойным щелчком в браузере. Интернет для занятий не нужен; внешние шрифты при отсутствии сети заменяются системными. Можно скопировать всю папку на другой компьютер или телефон и открыть там `index.html`.

Что есть: 12 последовательных уроков, 72 словарные позиции, 48 вопросов с проверкой, упражнения с венгерскими буквами, карточки с интервальным повторением, справочник и полезные фразы. Для завершения урока нужно ответить правильно на 3 из 4 вопросов. К урокам можно возвращаться и проходить их повторно.

Прогресс хранится **только в localStorage данного браузера**. При открытии файла в другом браузере или на другом устройстве он не переносится. Режим приватного просмотра и очистка данных сайта могут стереть прогресс. Озвучивание использует `speechSynthesis` браузера; если в системе нет венгерского голоса, звучание может быть неточным. Предварительно записанных аудиофайлов нет.

Учебные фразы о семье и происхождении — примеры, не готовые ответы для официального собеседования. Приложение покрывает начальные темы, а не заменяет живой разговор и продвинутый курс.

Проверка логики: `node --test tests/logic.test.cjs`. Проверка полного пути в Chrome: `node tests/browser-smoke.cjs` (требуется установленный Google Chrome, без управления рабочим столом).
