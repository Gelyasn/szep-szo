# Szép szó — венгерский с нуля

Публичная версия: https://gelyasn.github.io/szep-szo/ (сайт на GitHub Pages).

Откройте **`index.html`** двойным щелчком в браузере. Интернет для занятий не нужен: внешних шрифтов и сервисов нет. Можно скопировать всю папку на другой компьютер или телефон и открыть там `index.html`.

Что есть: 12 последовательных уроков, 72 словарные позиции, 48 вопросов с проверкой, упражнения с венгерскими буквами, карточки с интервальным повторением, справочник и полезные фразы. Для завершения урока нужно ответить правильно на 3 из 4 вопросов. К урокам можно возвращаться и проходить их повторно.

Прогресс хранится **только в localStorage данного браузера**. При открытии файла в другом браузере или на другом устройстве он не переносится. Режим приватного просмотра и очистка данных сайта могут стереть прогресс. Все слова и примеры с кнопкой звука имеют заранее созданные MP3-записи: венгерский голос в браузере не требуется, файлы работают даже без сети, если скачать всю папку. Записи произносятся в спокойном темпе; короткие слова замедлены сильнее. Выбор скорости («Очень медленно», «Медленно», «Обычно») сохраняется в браузере. Если браузер блокирует автоматическое воспроизведение, нажмите кнопку звука ещё раз.

Аудиозаписи сгенерированы локально свободной венгерской моделью [Piper hu_HU-anna-medium](https://huggingface.co/rhasspy/piper-voices/tree/main/hu/hu_HU/anna/medium), обученной на наборе данных с лицензией CC0. Модель в репозитории не хранится; метод воспроизведения и генерации описан в `scripts/`. Звучание синтезированное, но записи не зависят от голосов ОС.

Учебные фразы о семье и происхождении — примеры, не готовые ответы для официального собеседования. Приложение покрывает начальные темы, а не заменяет живой разговор и продвинутый курс.

Проверка логики: `node --test tests/logic.test.cjs`. Проверка полного пути в Chrome: `node tests/browser-smoke.cjs` (требуется установленный Google Chrome, без управления рабочим столом).
